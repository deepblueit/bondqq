# هنعديها: خطة ميدترم نوفمبر 2026

موقع مذاكرة لميدترم المستوى الرابع، نظم معلومات الأعمال (9 إلى 19 نوفمبر 2026).

- خطة بالساعة واليوم بتتظبط على مواعيد الصحيان والنوم والشغل، وبتتعاد من اللحظة الحالية لو حصل تأخير.
- لكل مادة: دروس بالشرح المصري، رسومات، حفظ بتريكات، أسئلة متوقعة بإجابات نموذجية بالفصحى وتصحيح ذاتي بالنقط، نماذج امتحانات بتايمر ساعة، فلاش كاردز، ملخص ليلة الامتحان، ومراجعة الصبح.
- وضعين: لوحدي، ومع يوسف.
- بيشتغل من غير نت بعد أول فتحة (على GitHub Pages).

## التشغيل
موقع ثابت بالكامل (HTML, CSS, JS). كل المكتبات والخطوط جوه الريبو.

- محليا: `python3 -m http.server` من فولدر الريبو، وبعدين افتح `http://localhost:8000`.
- أونلاين: GitHub Pages من فرع `main` والمسار `/ (root)`.

## الملفات
- `index.html` والواجهة في `assets/`.
- المحتوى في `data/<subject>.json` (eis, pf, iti, risk, stats, eb).
- محرك الخطة في `assets/js/plan.js`.
